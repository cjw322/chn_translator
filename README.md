# Chinese Text Annotator

## Description
This web app is a tool for Chinese language learners. After entering Chinese text, the application annotates it by adding pinyin on top and separating out individual phrases, which can help beginner/intermediate Chinese language learners read and pronounce the contents. Additionally, users can click on any phrase to generate a translation for that phrase, as well as see an option to view each character in the phrase's translation.

### Instructions

To run the backend, run `pip install -r requirements.txt` from the root directory. Then run `python app.py` to start the server.

To run the frontend, cd into the app/ directory, then run `npm install`. After installing packages, run `yarn start`.

Once the page loads, you can submit any text in the text box to annotate it.
